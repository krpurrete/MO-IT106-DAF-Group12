Descriptive Analysis: 

Using Python and pandas, the dataset was analyzed to determine the total number of products, product-type distribution, price statistics, and total inventory cost. 

The dataset contains 50 products, with Scooter (12) and Naked bike (7) being the most numerous product types. 

The average unit price is ₱257,872, with prices ranging from ₱48,000 to ₱995,000. The total inventory cost is ₱12,893,600. 

Pandas functions including df.describe(), value_counts(), and sum() were used, while str.split("/"), str[0], and str.strip() were used to extract the main product categories from the Product Types column.
